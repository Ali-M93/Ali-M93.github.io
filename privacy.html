Privacy Policy — Ali Gold Bot

Last updated: October 2026

Who uses this application

Ali Gold Bot is a personal project used only by its developer to operate the developer's own trading accounts. It is not distributed to other users.

Data accessed

  • Account information (balance, positions, orders) of the developer's own cTrader accounts.
  • Market price data needed to run the strategy.

How data is stored and protected

  • Access tokens and API credentials are stored only on the developer's own server and are never published or shared.
  • Trade logs are kept privately for performance review.
  • No data is sold, shared with third parties, or used for advertising.
